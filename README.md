# DevTalks – Guess the Speaker

Interactive mystery experience for **DevTalks · DYPIT**.

## Run

```bash
npm install
npm run dev
```

## Stack

- React + Vite (JavaScript)
- Tailwind CSS
- Framer Motion
- React Router
- React Icons

## Routes

- `/` — Landing
- `/guess` — Investigation game
- `/leaderboard` — Top investigators

Swap speaker data in `src/data/speakers.js`.
